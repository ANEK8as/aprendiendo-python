# Aprendiendo Python

Este repositorio es un calendario semana a semana donde documento mi progreso aprendiendo los conceptos básicos de Python, como parte de mi camino para especializarme en desarrollo backend.

Vengo de una base en Java (POO con BlueJ), así que gran parte del proceso ha sido traducir esos conceptos a la sintaxis y filosofía de Python.

## Estructura

Cada carpeta representa una semana de aprendizaje, con las prácticas y proyectos hechos en esa etapa.

### Semana 1 — Fundamentos

Temas cubiertos: variables y tipos de datos, condicionales (`if`/`elif`/`else`), loops (`for`, `while`, `break`), funciones, listas, `input()`, f-strings.

**Proyectos:**
- **`calculadora.py`** — Calculadora de calificaciones. Pide calificaciones al usuario hasta que escribe "fin", y calcula el promedio, la calificación más alta, la más baja, y si el promedio es aprobatorio.
- **`contador-palabra.py`** — Contador de palabras. Pide palabras al usuario hasta que escribe "fin", cuenta cuántas ingresó usando una función, y clasifica la lista como "larga" o "corta".

**Prácticas sueltas:** `variables.py`, `loops.py`, `while_loop.py`, `funciones.py`, `promedio.py`, `hola.py` — ejercicios individuales de cada tema mientras iba aprendiendo.
